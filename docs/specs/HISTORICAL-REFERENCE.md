## 3. 六类事件定义

**通用规则**（各类型除注明外一律适用）：

1. **事件时点** = 触发公告的 available_at 基准（巨潮公告发布时刻；日精度历史公告保守按 D+1 开盘前，`POINT-IN-TIME.md` §3.1）。
2. **事件实例** = 股票 × 事件类型 × 触发公告；一份触发公告一个实例。更正公告走 supersedes 链、原件永不覆盖，是否派生新实例按各类型规则。
3. **触发判定优先用公告元数据与预告/快报接口**（`DATA-SOURCES.md` §4：L1 层即可构建，不等全量 PDF）；主证据分级为 PDF 级（L3 已抓）/ 元数据级，随产出物标注。
4. **不自动猜**：类型或方向无法从公告明示信息判定的，标 UNDETERMINED 登记待人工归类（同 `ASHARE-RULES.md` §9 原则）。

### 3.1 业绩预告（含更正子类〔R10〕）

- **触发判定**：披露业绩预告公告（预增、预减、扭亏、首亏等法定预告类型），类型取公告明示值，无明示标 UNDETERMINED。预告类型记入事件属性。
- **更正子类**：预告更正公告（上修、下修）**本身触发新事件实例**，子类 REVISE_UP / REVISE_DOWN〔R10〕；方向判定按 `ASHARE-RULES.md` §9（公告明示优先，区间端点规则兜底，其余 UNDETERMINED）。同一原始预告的多次更正各记各的实例，更正件与原件走 supersedes 链并存。
- **数据来源**：巨潮公告元数据 + BaoStock 预告接口互核（`DATA-SOURCES.md` §2.3）。
- **可获得时点**：公告发布时刻（日精度 → D+1 开盘前）。
- **统计窗口起点**：公告日之后下一交易日开盘价（§4）。

### 3.2 业绩快报

- **触发判定**：披露业绩快报公告。快报的更正/差异说明公告不触发新实例，只走 supersedes 修正链（更正子类仅属业绩预告〔R10〕）。
- **数据来源**：巨潮公告元数据 + BaoStock 快报接口互核（`DATA-SOURCES.md` §2.3）。
- **可获得时点**：公告发布时刻（日精度 → D+1 开盘前）。
- **统计窗口起点**：公告日之后下一交易日开盘价（§4）。

### 3.3 定期报告的增速变化

- **触发判定**：定期报告（Q1/H1/Q3/FY）披露后，本期增速较**上一份定期报告**（按披露时间序）对应增速的变化量超过阈值 `GROWTH_DELTA_THRESHOLD`（百分点）才构成事件——披露本身不构成事件。增速科目两个口径分别判定：营业收入同比增速、归母净利润同比增速，任一超阈值即触发，触发的口径记入事件属性。**阈值为待 P4 校准冻结的参数**（同 R3 精神：先建库看变化量分布再定值），冻结前以预留值构建并全程标注"预留值"。
- **数据来源**：结构化财务（BaoStock 季频，按 pubDate 时点读取，`DATA-SOURCES.md` §2.2）计算增速；披露日以公告元数据定位。数值受 §6 修订口径声明约束——对比双方的数值均为最新修订口径，与当时公告口径可能不同，此局限随样本标注。
- **可获得时点**：定期报告披露时点（公告时刻；结构化数据按 pubDate → D+1 开盘前，`POINT-IN-TIME.md` §3.2）。
- **统计窗口起点**：披露日之后下一交易日开盘价（§4）。

### 3.4 限售解禁

- **触发判定**：限售股上市流通公告；**按解禁公告日为事件时点**。解禁日（可流通起始日）另记为事件属性，不作事件时点、不改变统计窗口起点；公告日晚于解禁日的异常情形如实记录两个日期并标注。
- **数据来源**：巨潮公告元数据（L1 类别标注）为主证据；解禁日从公告内容提取，提取不到标 DATA_GAP，不推算。
- **可获得时点**：公告发布时刻（日精度 → D+1 开盘前）。
- **统计窗口起点**：解禁**公告日**之后下一交易日开盘价（§4）。

### 3.5 大股东增减持

- **触发判定**：大股东（控股股东、实际控制人、持股 5% 以上股东及其一致行动人）增持/减持相关公告（计划披露、达到披露标准的进展、实施结果），**按公告日为事件时点**；方向（增持/减持）记入事件属性。以 L1 元数据的公告类别标注为准；类别粒度不足以区分计划/实施时先按"一公告一实例"纳入，粒度问题随 L1 质量实测（`DATA-SOURCES.md` 未决 5）在 P4 复核，不提前发明细分规则。
- **数据来源**：巨潮公告元数据（L1）。
- **可获得时点**：公告发布时刻（日精度 → D+1 开盘前）。
- **统计窗口起点**：公告日之后下一交易日开盘价（§4）。

### 3.6 回购

- **触发判定**：**首次公告**（回购预案/回购报告书）触发一个事件实例；**重要变更**（方案关键要素变更：回购金额区间、价格上限、回购用途、实施期限）触发后续事件实例，子类 FIRST / MAJOR_CHANGE。普通进展公告（如月度实施进展）不触发新实例。要素清单以本四项为准，P4 建库按公告类别实测后可增列并登记冻结。
- **数据来源**：巨潮公告元数据（L1）。
- **可获得时点**：公告发布时刻（日精度 → D+1 开盘前）。
- **统计窗口起点**：公告日之后下一交易日开盘价（§4）。

## 4. 衡量口径

**与决策合同结算方式直接一致**（`docs/specs/SETTLEMENT-REVIEW.md`）：起算价、窗口、复权、行业基准、停牌计时、失效判定的算式全部绑定该合同的同一计算式，本库不另立第二口径。本节只声明库侧的结构性约束与库特有的统计输出。

- **起算价**：事件时点之后下一交易日开盘价——与决策合同参考价同构（`ASHARE-RULES.md` §4：reference_open = 首个晚于事件时点的交易日开盘价）。
- **窗口**：h ∈ {1, 5, 20} 个交易日；20 日与主研究周期一致，1/5 日对应诊断周期。周期计数只在该股有成交的交易日递增，停牌暂停计时（`ASHARE-RULES.md` §6）。
- **超额收益**：个股收益 − 申万一级行业指数收益；行业指数取**事件时点当时版本**对应的申万一级指数（〔R8〕，`POINT-IN-TIME.md` §5.2）。
- **价格口径**：收益与超额收益用后复权价，由原始价 × 复权因子链逐日合成（`ASHARE-RULES.md` §7）；原始价与复权因子分开存储、分开读回（`POINT-IN-TIME.md` §5.4），历史窗口跨除权日必须后复权。
- **可成交性分类**：起算价日的可成交性按 `ASHARE-RULES.md` §5 判定（一字板判定用不复权原始价，§2.3/§2.4）；不可成交样本单独分类，不混入主比例。缺行情的样本（DATA_GAP）不得生成可成交性假设（§7 第 5 条）。
- **价格失效触发比例**：每事件样本按 20 日窗口计算"相对行业累计超额收益不利达到阈值"的触发与否；**不利按两侧分别统计**——跑赢侧（累计超额 ≤ −10%）与跑输侧（累计超额 ≥ +10%）分列，不合并。阈值当前为**预留值 10%**〔R3〕，校准程序见 §9。
- **统计产出为描述性统计**（分布、比例、样本数），不是预测概率（§7 第 3 条）。

## 5. 主群组的机械选定

**选定顺序**（逐层收窄，全库统一、程序执行、无人工裁量）：

1. **事件类型**（六类 + 子类：预告更正上修/下修、回购首次/重要变更）；
2. **申万一级行业（当时版本〔R8〕）**：2015–2021 区间用 2014 版分类与对应指数，之后用 2021 版；版本切换点在每次匹配结果的群组路径中**显式登记**（确切生效日 P1 以申万官方公告登记，`POINT-IN-TIME.md` 未决 1）；切换后不回溯重分类、不用新版本重解释旧样本；
3. **市值档（三档）**：按**事件时点的当时市值**〔R8〕（事件日收盘市值；市值口径与三档分界数值为 P4 冻结参数 `MARKET_CAP_TIERS`，冻结前不构建该层时逐层声明下限原因）；
4. **市场状态**：沪深 300 指数在事件时点的近 20 个交易日趋势向上/向下；默认算子 = 区间端点比较（期末收盘 ≥ 期初收盘为向上，否则向下），算子如需变更在 P4 校准期间登记。

**收窄规则**：

- 从事件类型层起逐层下钻；加入该层后样本数 ≥ `MIN_GROUP_SAMPLE`（**P4 冻结参数**，冻结前任何查询不得临时设定）才进入，主群组 = 满足下限的**最深层**；下一层样本数低于下限即停止收窄。
- **同时输出每一父层**（含事件类型层、全库基础层）的样本数与基础比例，同一统计口径。
- **嵌套声明**（固定文本，随产出物与 A/J 参照块强制携带）：群组路径上各层相互嵌套，是同一证据的逐次切片，**不是独立证据**；多个嵌套群组的相似比例不构成独立确认。
- **不降档凑样本**：样本不足时只停在上层或报缺口（§8）；不得放宽匹配维度（扩大时间窗、合并相邻行业、跳过市值档/市场状态层）来凑样本，不得为单个查询事后调低 `MIN_GROUP_SAMPLE`。

## 6. 修订口径声明〔R4〕

原文（与 `docs/PLAN.md` §3、`DATA-SOURCES.md` §5、`POINT-IN-TIME.md` §6 同源）：

> **修订口径声明：一次性回填 2015–2026 拿到的是当前最新修订值，与当时公告值可能不同且不可复原；历史参照库的事件主证据以公告 PDF 原文为准，结构化数据做辅助。**

落点：

1. 该声明**原样出现**在本库全部消费回填结构化财务的输出中（校准报告、群组匹配结果对象、A/J 参照块模板、界面展示），不改写、不省略；回填结构化数字旁标注"最新修订口径"（判定同 `POINT-IN-TIME.md` §6）。
2. **事件主证据以公告 PDF 原文为准**：证据分级 PDF 级 / 元数据级随产出物标注（§3 通用规则 3）；进入研究引用的关键样本按 `DATA-SOURCES.md` §4 L3 升级为 PDF 级并交叉核对。
3. 六类事件的**触发判定不等全量 PDF**：用公告元数据 + 预告/快报接口（L1）即可构建（`DATA-SOURCES.md` §4）；增速变化事件（§3.3）数值天然来自结构化数据，只能标"最新修订口径"。

| 5 | No WDL-to-spread conversion without the corresponding actual outcome data | 无对应实际结果数据的口径不得换算 | 无真实行情的样本不得生成假设结果：缺涨跌停/可成交判定数据的不自动生成可成交假设（§4）；退市股 DATA_GAP 区段不得以邻近样本代替；描述性比例不得换算为预测概率、方向建议或任何"等效口径"数字 |
| 6 | Existing method and answer identities remain immutable | 既有方法与结论身份不可变 | 参照库重建、校准、参数冻结产生的新版本走数据与适配器版本轴（三条版本轴，`docs/ARCHITECTURE.md`）；不重写既有研究结论对象；既有参照产出的历史身份与旧 run 引用永远可解析（`POINT-IN-TIME.md` §7 不可变判定） |

**对接验收**：第 1、6 条由程序对参照块与封存池绑定做校验；第 2、3、5 条由产出物模板强制字段核对，缺失即不得出库；第 4 条在研究侧验收（`RESEARCH-METHOD.md` §6）。

## 8. 产出物：群组匹配结果对象

每次匹配查询产出一个群组匹配结果对象，字段：

| 字段 | 定义 |
|---|---|
| 匹配请求身份 | 股票代码、事件类型（含子类）、事件时点、资料截点 |
| 群组路径 group_path | 逐层记录：事件类型层 / 行业层（含分类版本与切换点标记）/ 市值档层 / 市场状态层；每层含样本数与停留原因（继续下钻 / 因下限停止） |
| 主群组 | 满足下限的最深层标识与样本数（§5） |
| 父层结果 | 各父层样本数与基础比例（同一统计口径） |
| 基础比例 base_rate | 1/5/20 日超额收益的方向分布；价格失效触发比例（两侧分列，§4） |
| 嵌套声明 | §5 固定文本，强制携带 |
| 数据缺口 data_gaps | 样本级 DATA_GAP（退市股行情缺失、关键时点缺失、L3 未升级的元数据级证据）逐一列名，不静默 |
| 版本绑定 | 方法版本、数据与适配器版本（三条版本轴）、输入事实 available_at 上限、materialized_at |
| 修订口径声明 | §6 声明原文，原样携带 |

**匹配为空的规则**：

- 事件类型层即无样本（或全库无该类型样本）时，产出物**只有缺口、没有群组**：空群组路径 + data_gaps + 声明，不出现任何样本数 ≥ 1 的群组行与任何比例数字。
- **缺口是合法产出**：进入研究 limitations（`RESEARCH-METHOD.md` §7.3 缺口不冒称确认）；不降档凑样本（§5），不虚构全库比例冒充群组基础比例。

## 9. 价格失效阈值的校准程序〔R3〕

1. **现状**：预留值 10%（`docs/PLAN.md` §1），**不是冻结值**。校准完成前，本库一切输出中该值只标"预留值"，不冒称冻结值。
2. **P4 实测**：本库建成后，用全部六类事件样本实测预留值 10% 下的触发率分布——按事件类型、各群组分列，两侧口径分开（§4）。
3. **产出**：失效阈值校准报告（触发率分布、建议值、对主统计失真风险的影响评估），随 P4 停止条件交付（`docs/PLAN.md` §8 P4："失效阈值触发率报告产出"）。
4. **P5 冻结**：冻结方法与规则时一并冻结阈值；冻结后评价窗口内不改任何阈值，含价格失效条件（`docs/PLAN.md` §7〔R13〕）。
5. **顺序不可倒置**：先冻结阈值再建库违反实证顺序（`docs/REVIEW-20261025.md` R3）；本合同的 P4 参数（§3.3、§5）同此精神。

## 10. 非目标

- **不做三市场回放**：不移植 Metis 足球域的三方向（胜平负）历史回放机制；本库只做事件后表现的描述性统计。
- **不做假设库**：不生成假设性事件、不造代理样本；数据缺口以 DATA_GAP 形式存在（§8），不转化为任何统计数字（§7 第 5 条）。
- **不直接驱动研究**：产出只供参照，进入 A/J 上下文受 §7 判断义务约束；参照比例不自动生成结论、不构成自动改判依据。
- **不扩展第七类事件**：问询函属风险项维度（`RESEARCH-METHOD.md` §4 第 7 条、`ASHARE-RULES.md` §9），不入六类；更正公告并入业绩预告子类〔R10〕，不另立类型；分红送转、定增不建群组统计（作为研究维度的公告输入照常存在）。
