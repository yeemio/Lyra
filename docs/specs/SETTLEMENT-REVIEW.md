## 1. 合同范围

**管**：结算口径（参考价、窗口计时、方向命中、超额收益、最大不利波动、失效触发、可成交性消费）、复盘分母（全机会分母）、不重叠样本规则、价格失效条件的定义与校准顺序、预注册主指标与评价窗口纪律、周末复盘中结算动作的口径。

**不管**：

- A 股市场规则本体（涨跌幅系数、一字板判定、停牌识别、复权因子、可成交性判定算法）——`ASHARE-RULES.md`；本合同只消费其输出；
- 结论对象结构与决策选项语义——`RESEARCH-METHOD.md`；本合同的结算结果回填其占位区；
- 研究时段、触发、溢出判定、周末复盘流程入口——`SCHEDULING.md`；
- 执行侧分类的实现（MISSED_WINDOW、UNKNOWN 落库）——`EXECUTION-KERNEL.md`；本合同只定义它们在分母中的位置；
- 历史参照库的群组构建——`HISTORICAL-REFERENCE.md`（其衡量口径与本合同结算口径直接对应，PLAN §5）。

**SR-1.1（边界判定）** 任何"一字板怎么判、复权因子怎么算"的规则出现在本文件即为越界（归 `ASHARE-RULES.md`）；反之，任何"这个结论算不算命中、进不进分母"的规则不落在本合同即为缺口。证伪：对任一条规则可唯一指认归属合同。

## 2. 每个结论都结算

**SR-2.1（结算主体）** 全部结算字段由**程序从行情原件计算**：个股原始价与复权因子、申万行业指数点位，全部取自原件库封存数据（`DATA-SOURCES.md`、`POINT-IN-TIME.md`）。**模型不参与结算**——任何 A/J 输出不构成结算依据（移植 `metis/packages/result-review` `truth.modelClaimIsNotAuthority`：模型文字永远不构成权威）。证伪：结算程序的全部输入引用中不含任何模型输出哈希。

**SR-2.2（结算字段）** 每个产生结论对象的 attempt（`RESEARCH-METHOD.md` §8），窗口走完后结算以下字段：

| 字段 | 定义 | 放弃结论 |
|---|---|---|
| 方向命中 | 三态 HIT / MISS / N_A：跑赢 = 20 日超额收益 > 0 命中；跑输 = 超额收益 < 0 命中；恰好为 0 两侧均不命中（严格不等） | N_A，不参与方向命中 |
| 超额收益 | 从参考价起算 20 个有成交交易日（SR-3.3），个股后复权收益 − 申万一级行业指数收益；指数版本按结论资料截点当时分类冻结〔R8〕 | 照常计算并记录 |
| 最大不利波动 | 窗口内逐日（有成交交易日收盘时点）累计超额序列的极值：跑赢取最小值（最大负超额）、跑输取最大值（最大正超额）；如实记录，不为 0 截断 | N/A（无不利方向可定义） |
| 失效触发 | 是否触发价格失效条件（§6）+ 首个触发日；采样粒度为日线收盘时点（无日内数据，PLAN §1） | N/A |
| 可成交性 | 按 `ASHARE-RULES.md` §5 四值（可成交 / 一字涨停不可成交 / 一字跌停不可成交 / 停牌不可成交）+ §6 长期停牌单独类 | N/A（无交易意图） |
| 窗口状态 | 未到期 / 已到期已结算 / 结算异常（具名登记） | 同左 |

数值纪律：方向命中与失效触发的比较一律用精确十进制定点运算（移植 Metis `ExactDecimal` 思想，`metis/packages/result-review` decimal 模块），禁止浮点直接相等与阈值比较；精度常量见未决 3。

方向命中的完整取值表（程序判定，e_window 即 20 日超额收益）：

| disposition | 判定条件 | 结果 |
|---|---|---|
| RESEARCH_OUTPERFORM | e_window > 0 | HIT |
| RESEARCH_OUTPERFORM | e_window ≤ 0 | MISS |
| RESEARCH_UNDERPERFORM | e_window < 0 | HIT |
| RESEARCH_UNDERPERFORM | e_window ≥ 0 | MISS |
| ABSTAIN | —（不参与方向命中） | N_A |

**SR-2.3（回填纪律）** 结算结果只写入结论对象的**结算占位区**（`RESEARCH-METHOD.md` §8）；研究字段一经写入不可变，回填不得改动 disposition、证据引用等任何研究字段。证伪：结算前后结论对象的研究字段哈希不变。

**SR-2.4（未到期不提前结算）** 窗口未走完（20 个有成交交易日未满）的结论标"未到期"，不提前结算、不做预测性回填；到期后在下一个周末复盘结算（§10）。证伪：注入窗口仅走 12 个交易日的结论，读回窗口状态 = 未到期、结算字段全空。

## 3. 参考价与窗口（含前置裁定）

**SR-3.1（统一参考价裁定）** 参考价一律锚定**结论完成时刻**，定义为：**结论完成后第一个有成交交易日的开盘价**。程序规则：reference_open = 满足 open_time > 结论完成时刻 t、且该股当日有成交的第一个交易日的开盘价（`ASHARE-RULES.md` §4 规则加"有成交"限定，以覆盖 §6 停牌顺延）。

> **裁定回执**：本条即 `SCHEDULING.md` 未决 3 移交本合同的待决项的裁定，冻结于本合同。任何情形不得改锚事件时刻或公告时刻——参考价锚定的是"结论可得之后"，把尚未做出的结论假装按更早价格成交即前视。SCHEDULING 未决 3 自本合同冻结起关闭，其文本侧标注随该合同下次变更程序进行，本合同不代改。

**SR-3.2（情形实例化）** 统一定义对四类情形的落点：

| 情形 | 结论完成时刻 t | 参考价 | 一致性依据 |
|---|---|---|---|
| 事件后研究按窗完成 | 交易日 08:00–09:15 之间 | 当日开盘价（t 早于开盘） | `ASHARE-RULES.md` §4 |
| **溢出降级者**（SC-6.2 降级并入次日周度队列） | 次日以周度类型实际完成的时刻（当晚） | **再次一交易日开盘价，不回溯原事件日** | 本裁定：降级者资料截点已更新为并入日周度截点（SC-6.2），结论在 t 才存在 |
| 周末 / 非交易日完成（含 SC-3.3 非交易日启动的事件后研究） | 非交易日 | 下一交易日开盘价 | `ASHARE-RULES.md` §4、SC-10.2 |
| 完成后首交易日停牌 | — | 顺延至复牌首日开盘价，可成交性 = UNFILLABLE_SUSPENDED | `ASHARE-RULES.md` §6 |

证伪：构造一降级者（事件日 D，D+1 晚完成周度研究），读回参考价 = D+2（D+1 之后首个交易日）开盘价，而非 D 或 D+1 的开盘价。

**SR-3.3（窗口计时）** 参考价日 = 窗口第 1 个有成交交易日；窗口结束日 = 第 20 个该股**有成交**的交易日——**停牌日不计入 20 日计时**，计数器只在有成交交易日递增（`ASHARE-RULES.md` §6）；终点价 = 窗口结束日收盘价。超额收益 = (P_end/P_ref − 1) − (I_end/I_ref − 1)：P 为个股后复权价（原始价 × 复权因子链，`ASHARE-RULES.md` §7），I 为申万一级行业指数点位。停牌超过 20 个交易日的样本单独分类（SUSPENDED_OVER_20D，`ASHARE-RULES.md` §6），窗口照走（复牌后继续），不并入主统计。证伪：构造窗口内含 5 个停牌日的样本，读回窗口结束日 = 参考价日后第 25 个交易日（停牌日不计时）。

**SR-3.4（计算基准：逐日累计超额序列）** 对窗口内每个该股有成交的交易日 d：e_d = (P_d_close / P_ref − 1) − (I_d_close / I_ref − 1)，其中 P_d_close 为当日后复权收盘价（`ASHARE-RULES.md` §7），I_d_close 为申万一级行业指数当日收盘点位；e_window（20 日超额收益）= e_(窗口结束日)。SR-2.2 的最大不利波动与 SR-6.1 的失效触发均取自该序列，不另行计算口径。证伪：对同一样本，MAE、失效触发、e_window 三个字段可由同一份逐日序列重算得出。

**SR-3.5（行业基准版本冻结）** 行业基准（申万一级行业指数及其分类版本）在结论产生时按资料截点当时版本〔R8〕冻结进结论对象（2015–2021 区间用 2014 版，之后用 2021 版，`ASHARE-RULES.md` / `HISTORICAL-REFERENCE.md` 同口径）；结算只读取冻结值，不得因数据源后续更新分类版本而事后改基准重算。证伪：构造一个资料截点在版本切换附近的结论，结算读回的指数身份与当时版本一致，重放结算结果不变。

## 4. 复盘分母（全机会分母）

移植 Metis 全机会分母思想（`metis/packages/result-review` `comparison.denominators`：全部机会、选择、弃权、技术失败、未知、取消、迟交各自计数；技术失败非弃权；未知单列）。

**SR-4.1（分母单位与终态互斥）** 分母单位 = **研究准入 attempt**（事件后 / 周度 / 事件前全部时段，每条准入记录一个单位）。每个 attempt 在复盘快照时点恰好落一个终态类：

| 终态类 | 定义 | 出处 |
|---|---|---|
| SELECTED（选择） | 产生结论且 disposition ∈ {RESEARCH_OUTPERFORM, RESEARCH_UNDERPERFORM} | `RESEARCH-METHOD.md` §3 |
| ABSTAIN（放弃） | 产生结论且 disposition = ABSTAIN | 同上 |
| TECH_FAILURE（技术失败） | 执行或结构校验失败（A 未过结构校验、执行异常落库） | `EXECUTION-KERNEL.md` 分类的消费 |
| MISSED（错过） | 见 SR-4.2 两个子类 | EK-6.2、EK-9.2 |
| UNKNOWN | 远端结果未知的 attempt（不重发、不自动重采样） | `EXECUTION-KERNEL.md` UNKNOWN 处置 |
| PENDING | 仍在队列顺延（SC-5.3 从未发送者的顺延），未到终态 | 单列计数，不并入任何终态比例 |

证伪：任一复盘快照中，各终态类计数之和 = 快照时点前的全部准入数（无重叠、无遗漏）。

**SR-4.2（错过子类）** MISSED 细分两个子类，各自独立计数：

- **MISSED_OVERFLOW（溢出降级）**〔R6〕：事件后研究降级并入次日周度队列的 attempt（`SCHEDULING.md` §6 / SC-6.2、EK-9.2 标注"事件后研究未按最高优先窗完成"）。降级者若次日以周度执行完成并产生结论，其**终态按结论计入 SELECTED / ABSTAIN，同时保留 MISSED_OVERFLOW 标注独立计数**（并存计数；同 Metis"迟交"与选择/弃权并存的先例，`metis/docs/specs/SPEC.md` §9.3 late_completed 经 EK-6.3 引入）；降级后仍未按周度窗完成的，终态 = MISSED。
- **MISSED_WINDOW（截止未按窗完成）**：已启动而完成截止到期未完成的 attempt（EK-6.2 `MISSED_WINDOW`）。

**SR-4.3（不可成交视图）** SELECTED 样本按 `ASHARE-RULES.md` §5/§6 另挂可成交性分类（FILLABLE / UNFILLABLE_LIMIT_UP / UNFILLABLE_LIMIT_DOWN / UNFILLABLE_SUSPENDED / SUSPENDED_OVER_20D），**单独分类、独立计数、不混入主统计**（`ASHARE-RULES.md` §5 处置）。不可成交样本仍照常结算（SR-2.2）。ABSTAIN 不参与可成交性判定。

**SR-4.4（三条禁令）** ①技术失败不冒充放弃：TECH_FAILURE 与 ABSTAIN 互斥且各自独立计数；②UNKNOWN 不回写为失败：UNKNOWN 计数永久保留为"未知（非 0）"（Metis 先例：未知显示未知、不记零），不得并入 TECH_FAILURE 或任何比例的分母；③PENDING 不冒充任何终态。证伪：注入一批技术失败与 UNKNOWN 后，读回 ABSTAIN 计数不变、UNKNOWN 计数独立可见。

**SR-4.5（主统计分母）** 主指标与方向命中率的分母 = **SELECTED ∩ FILLABLE ∩ 不重叠（§5）∩ 已到期**：只有可成交、未被不重叠规则排除、窗口已走完的选择样本进入主统计；其余各类在分母视图中独立计数、可见但不混入。

**SR-4.6（分母快照与可重放）** 复盘分母在**固定快照**上计算（移植 Metis `denominators` 的固定 snapshot 语义）：每次复盘登记快照身份（快照时点 + 覆盖的准入范围），分母视图可从原件库与执行记录完整重放；后续新增结算与修订不改写已发布快照，只产生新快照。证伪：对任一历史快照身份重放计算，读回各终态类计数逐项一致。

**SR-4.7（分母视图一览）** 每次复盘快照发布以下计数项，全部独立可查、口径固定：

| 计数项 | 口径 |
|---|---|
| 全部准入 attempt | 快照时点前的全部准入记录（分母的"全机会"基数） |
| SELECTED / ABSTAIN / TECH_FAILURE / MISSED / UNKNOWN / PENDING | 终态互斥六类（SR-4.1） |
| MISSED_OVERFLOW / MISSED_WINDOW | MISSED 子类；前者含"降级后完成"者的并存标注（SR-4.2） |
| FILLABLE / 三类不可成交 / SUSPENDED_OVER_20D | SELECTED 上的可成交性视图（SR-4.3） |
| 不重叠排除计数 | overlap_excluded = true 的选择样本（SR-5.1） |
| 未到期计数 | 窗口未走完、尚未结算的结论（SR-2.4） |
| 主统计分母 | SR-4.5 交集，单独报出 |

## 5. 不重叠样本规则

**SR-5.1（规则与程序判定）** 同一股票，**上一结论的 20 日周期（SR-3.3 窗口）结束之前产生的新结论，不进入汇总统计**。程序判定：新结论带 `overlap_excluded` 布尔与排除来源指针；判定基准 = 同股时间上最近的前一个结论对象（无论其本身是否被排除、是否可成交），新结论参考价日 ≤ 前一结论窗口结束日即排除。样本身份可程序判定、可审计重放。理由：同一股票相邻结论的自相关会虚增效果（PLAN §7；不重叠规则是 A 股必要扩展，足球每场独立无此问题，`docs/REVIEW-20261025.md` §二）。

示例（锚定"最近前一个结论"而非链式回溯第一个）：结论 A 参考价日 3-02、窗口结束日 3-30；同股结论 B 参考价日 3-20（落在 A 窗口内）→ B 被排除；同股结论 C 参考价日 4-10 —— C 与 B（最近前一个结论，窗口结束日约 4-17）比较仍落在 B 窗口内 → C 同样被排除，即使 C 已晚于 A 的窗口结束日。证伪：构造同股两个结论（新结论参考价日落在前一窗口内），读回新结论 overlap_excluded = true 且主指标分母不含它；再构造第三个结论验证锚定最近前一个结论（而非最早的 A）。

**SR-5.2（排除不豁免）** 被排除的结论仍**照常单独结算与展示**（SR-2.2 全字段），只是不进汇总统计；排除是统计口径，不是丢弃。证伪：被排除结论的结算字段读回完整。

## 6. 价格失效条件〔R3〕

**SR-6.1（定义，预留值）** 预留阈值 **10%**：窗口内（SR-3.3）任一有成交交易日收盘时点的累计超额收益向**不利方向**达到该值即触发——跑赢为 e_d ≤ −10%，跑输为 e_d ≥ +10%。记录"是否触发 + 首个触发日"。

**SR-6.2（只记录）** 失效触发**只记录，不代表止损交易**：不产生任何信号、不改变结算、不触发任何研究动作（§12）。放弃结论不适用（N/A）。采样粒度为日线收盘（无日内数据）。

**SR-6.3（校准与冻结顺序）** 该 10% 是**预留值而非冻结值**：P4 历史参照库建成后，先实测六类事件的触发率分布（`HISTORICAL-REFERENCE.md` 衡量口径含"触发价格失效条件的比例"，PLAN §5），据此校准，P5 冻结方法与规则时一并冻结（PLAN §8 P4/P5 停止条件）。理由〔R3〕：高贝塔股票 20 日内相对行业 −10% 超额回撤并不罕见，触发率可能高到让主统计失真；先冻结再建库违反实证顺序。**评价窗口内不改任何阈值**（与 SR-7.4 同一纪律）。

## 7. 预注册主指标〔R13〕

**SR-7.1（唯一主指标）** P5 冻结时预注册**唯一主指标**：**个股**可成交选择样本（SR-4.5 分母，不含宽基，SR-8A.5）的 **20 日相对行业超额收益方向命中率**。不设第二主指标、不设综合分。

**SR-7.2（子分组一律描述性）** 行业、市值档、事件类型、市场状态子分组一律为**描述性统计**：只报计数与比率，不做显著性宣称、不报告 p 值与置信区间（防止评价时多重比较，〔R13〕）。

**SR-7.3（最小样本量）** 主指标分母（不重叠、可成交、已到期样本）低于声明下限时，**只报描述统计**，不报命中率作为效果结论。下限数值 P5 冻结；建议参考：**每方向 ≥ 30**。届时分方向报告样本量，任一方向不足即整体降级为描述统计。

**SR-7.4（评价窗口纪律）** 评价窗口内：**不改主指标定义、不改任何阈值（含 §6）、不选择最好子集充当事后验收集**（移植 `metis/docs/specs/SPEC.md` §11.2"不能反复查看结果后选择最好子集作为验收集"）。主指标定义在 P5 冻结时一次性写入观察合同，评价只读取。

**SR-7.5（首评报告最低内容）** 第一次效果评价（SR-8.2）的报告至少包含：主指标值与分母构成逐项计数（§4 全部终态类与视图）、分方向样本量、SR-7.3 下限判定结果、描述性分组表（SR-7.2）、失效触发率与阈值校准依据回引（SR-6.3）、"功效有限、表述克制"限定语（SR-8.4）；不包含任何显著性检验与跨期趋势结论。

## 8. 两条验收线与第一次效果评价

**SR-8.1（两条验收线）** 移植 `metis/docs/specs/SPEC.md` §11.2：**工程价值**（数据实际送达、时点正确、历史不丢、状态准确、恢复安全）与**预测效果**（在事前固定的完整机会范围内评价）是两条独立的验收线；**不把更快、更便宜、更多成功运行当作更准**；工程完成不能替代效果评价。首评前的周报只走第一条线（SC-11.4），第二条线自 SR-8.2 时点起。

**SR-8.2（第一次效果评价时点）** 最早 **2027 年 5 月底**：2027 年 3–4 月年报 + 一季报财报季是第一个完整财报季，加 20 个交易日结算期（PLAN §7）。此前**不做任何效果评价**——无命中率类输出（SC-11.4 证伪项）。

**SR-8.3（首评前只评价工程与流程质量）** 指标集：①资料送达率（各时段资料截点前封存完成比例，DATA_GAP 标注率分列）；②按窗完成率（对照 MISSED / 降级计数）；③结算完整率（到期应结算结论中已正确结算比例，结算异常具名登记）；④泄漏测试通过（四类时点对象，PLAN §10、`POINT-IN-TIME.md`）；⑤恢复演练通过（`EXECUTION-KERNEL.md` 恢复路径）。载体 = 周末周报（SC-11.4）。

**SR-8.4（功效与克制）** 预计首评时点不重叠样本约 **120 个**上下、按方向三分后每类 **30–40 个**，功效有限：结论表述克制——只报主指标值、样本量与描述性分组，不做方向性宣称、不做跨期比较结论（PLAN §7）。

**SR-8.5（评价时点的截尾规则）** 首评时点窗口未走完的样本**自然排除**出主统计分母（SR-4.5"已到期"条件），不做部分窗口外推或截尾估算；被排除者的未到期计数在报告中可见（SR-4.7）。证伪：首评报告的主指标分母中不存在任何窗口结束日晚于评价时点的样本。

## 8A. 宽基 ETF 结算〔R18〕

出处 `docs/FREEZE-P0-20261025.md` R18。除本节列明的差异外，宽基结论沿用本合同全部规则（SR-2 结算主体与回填纪律、SR-3.1 参考价锚定、SR-4 分母、SR-5 不重叠、SR-8 两条验收线）。

**SR-8A.1（结算标的与收益）** 结算标的为 ETF 的**跟踪指数点位**（避开 ETF 折溢价与分红除息）：r_window = I_end / I_ref − 1，I_ref 为参考价日指数开盘点位，I_end 为第 20 个交易日指数收盘点位；逐日序列 r_d 同 SR-3.4 结构（无行业项）。价格指数不含分红，口径声明随结算结果展示。证伪：同一样本的 r_window、最大不利波动、失效触发可由同一份逐日序列重算。

**SR-8A.2（方向命中）** `RESEARCH_UP`：r_window > 0 为 HIT，否则 MISS；`RESEARCH_DOWN`：r_window < 0 为 HIT，否则 MISS；`ABSTAIN` 为 N_A。

**SR-8A.3（可成交性）** 按 ETF 不复权原始价与 `ASHARE-RULES.md` §2.1 的 ETF 系数判定一字板；ETF 行情缺失时可成交性记 DATA_GAP，不推定可成交。

**SR-8A.4（失效阈值）** 预留值 **5%**（不利方向的 20 日内累计绝对收益），与 SR-6.3 同程序：P4 以跟踪指数自身历史实测触发率后校准，P5 冻结。

**SR-8A.5（统计隔离）** 宽基结论**不进入 SR-7.1 主指标及其分母**；分母视图（SR-4.7）中宽基与个股分开报出；宽基方向命中率一律为描述性统计，不做显著性宣称、不适用 SR-7.3 最小样本量判定。证伪：主指标分母中出现任一 BROAD_ETF 结论即违约。

## 9. 诊断周期

**SR-9.1** 5 日、60 日超额收益（同一参考价起算口径，SR-3.3）**只记录**在结算字段扩展区：不参与决策（不进研究链输入）、不参与主指标与任何汇总统计（PLAN §1 诊断周期）。证伪：主指标与周报的计算输入中不含 5/60 日字段的引用。

## 10. 周末复盘流程对接

流程本体在 `SCHEDULING.md` §11（SC-11.1–11.4），本合同只冻结结算侧口径：

**SR-10.1（到期判定与结算时点）** 窗口结束日 ≤ 本周五的到期结论，在本周末复盘中结算（SC-11.2）；未到期者顺延至后续周末，状态可见。结算与档案更新（原件哈希核对、缺口清单刷新，SC-11.3）都在周末复盘执行。

**SR-10.2（零模型调用）** 周末复盘全程零模型调用（SC-11.1）；结算程序的全部输入为行情原件与指数点位（SR-2.1）。证伪：复盘运行时段 permit 表新增数为 0（同 SC-11.1 断言）。

**SR-10.3（周报无效果字段）** 周报只含工程与流程质量指标（SR-8.3 列集 + 溢出降级计数、UNKNOWN / 阻断计数、预算使用与顺延堆积、缺口清单变化，SC-11.4），**无任何收益、命中率类字段**。

**SR-10.4（结算异常处置）** 结算遇到数据缺口（个股或指数某日行情缺失且非停牌、复权因子缺失等）时，窗口状态落具名结算异常，逐条登记、周报可见，**不静默跳过、不用替代数据补算**；缺口补齐后在下个周末复盘重结算并产生新快照（SR-4.6）。证伪：注入指数缺一日数据的样本，读回具名异常记录，且无任何以替代值补算的结算结果。

## 12. 非目标

- **不做资金结算**：无单位、无盈亏金额、无退款概念（PLAN §9）；Metis 退款类分母不移植（§11）。
- **不做正式采用**：adoption 恒为 false，研究结论是唯一层，无候选 / 正式双层。
- **不做盘中止损信号**：失效触发（§6）只是记录，不产生交易或研究动作。
- **不做方法自动改进**：复盘只产生**方法建议候选**（记录、供 Owner 人工决策），**永不自动激活**（Metis 先例：`result-review.propose` activated: false）；任何方法变更走 `docs/PLAN.md` 修订程序、产生新方法版本轴，不以复盘结果自动触发。
- **不做效果评价前移**：2027 年 5 月底前无任何效果类输出（SR-8.2）。
