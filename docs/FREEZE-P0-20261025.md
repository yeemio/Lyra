## 四、宽基维度集（R18，方法正文 P2 冻结）

1. 估值分位：指数市盈率、市净率在自身历史中的分位；
2. 成分盈利趋势：成分股最新财报汇总增速（由已入库财务数据聚合，缺口如实声明）；
3. 宏观与政策：官方发布的货币、财政与监管政策（首版可后置，后置即界面明示缺口）；
4. 资金：全市场融资余额变化、ETF 份额变化；
5. 价格行为与市场宽度：指数趋势、成交额、涨跌家数；
6. 风格相对：大小盘相对强弱（四只宽基之间）；
7. 历史状态参照：指数自身历史在同类状态下的后续表现（P4 构建，判断义务同方法 14）。
